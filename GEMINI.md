# Sony Alpha Việt (Gemini CLI)

Extension này cung cấp skill `sony-alpha-viet` (thư mục `skills/sony-alpha-viet/`) và MCP server `sony-alpha-viet`.

Khi người dùng muốn dịch menu/tài liệu Sony Alpha sang tiếng Việt, hoặc viết/audit blog máy ảnh tiếng Việt chuẩn SEO + AIO:
1. Kích hoạt skill `sony-alpha-viet` và làm theo `skills/sony-alpha-viet/SKILL.md`.
2. Dùng các tool MCP của server `sony-alpha-viet` thay cho tên `mcp__sony-alpha-viet__*` nhắc trong skill (cùng tên tool, khác tiền tố).
3. Không có MCP: làm thủ công theo `references/` và ghi rõ "chưa kiểm bằng MCP".
